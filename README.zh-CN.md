# 几何声音实验室 Geometry Sound Lab

面向盲人和低视力学生的几何教学桌面应用。程序把二维几何图形转化为**可听的声音轨迹**：
一个单声部声音点沿图形轮廓移动，横坐标映射为左右声像，纵坐标映射为音高，
顶点、交点和图形闭合分别用不同的提示音标记，帮助学生通过听觉建立几何概念。

- 技术栈：Electron + React + TypeScript + Vite + Web Audio API + SVG
- 完全离线运行，不依赖任何云端服务
- 支持键盘完成全部核心操作，兼容 VoiceOver / Narrator 等屏幕阅读器
- 语音默认 **1.5 倍速**（盲人用户听力习惯），设置中可在 0.5–3.0 倍间自由调节
- **建议佩戴耳机使用**，以便准确分辨左右声像
- **中英文双语界面**：设置面板顶部 "Language / 语言" 一键切换，覆盖全部界面文案、
  语音播报、图形名称与描述、教学练习题、语音导览与启动引导；语音自动跟随语言切换人声
  （英文选 Ava/Samantha 系，中文选婷婷 Tingting 系，Premium/Enhanced 优先）

## 使用说明（中文）

### 界面布局

| 区域 | 内容 |
| ---- | ---- |
| 左侧 | 图形库（仅在图形播放 / 手势演奏页显示）：基础线条、多边形、圆与曲线、坐标与函数、自定义图形 |
| 中间 | SVG 坐标区域：网格、图形轮廓、顶点、交点、起点方块、方向箭头、当前声音点 |
| 右侧 | 设置：播放模式与速度、音高范围与量化、音色、三路音量、提示音开关与试听、显示主题 |
| 底部 | 播放控制按钮（仅图形播放页显示）+ 状态栏 + 屏幕阅读器 aria-live 播报区域 |

顶部可切换四个功能页：**图形播放、教师编辑器、教学练习、斜率对比**。

### 启动语音引导（为盲人学生设计的开机流程）

程序**每次启动会自动朗读**基础操作说明（Space 播放、↑↓ 选图形、E 自由探索、
? 打开可语音逐条朗读的快捷键表、T 随时进入导览），然后语音询问：**"要现在开始语音教学导览吗？按 Enter 开始，按 Escape 跳过。"**

- 按 <kbd>Enter</kbd>（或 T）→ 直接进入 13 步语音导览
- 按 <kbd>Escape</kbd> → 跳过，语音提示"随时按 T 可再进入导览"
- 引导期间其他快捷键静默，避免学生误触；屏幕上同步显示同内容的无障碍对话框
- **应用启动永远是英文界面**；语言切换在设置中，作用于当次会话

### 乐器创作模式（Instrument / Composition Mode）

按顶部 **🎼 Instrument** 标签进入全新的艺术模式——**描绘图形的过程本身就是演奏**：

```text
GEOMETRY → GESTURE → PERFORMANCE → THEME → TRANSFORMATION → COMPOSITION
```

- **实时演奏**：拖动鼠标/触控（或切换摄像头手势输入）描图，Y 位置量化到演奏音阶
  （默认 C Dorian，可选大/小调五声、半音阶，带迟滞防抖 + 滑音），X 是声像（±0.75），
  速度控制力度与明暗（非线性+平滑），曲率控制颤音深度，方向产生细微 articulation；
  转角触发调内轻拨弦重音，闭合图形播放 root→fifth→主和弦终止式
- **主题提取**：完成图形后，轨迹经清理→弧长重采样→重要点检测→音阶量化→节奏量化
  （1/16 网格），生成 8–12 音符的可记忆动机并自动回放
- **几何决定身份，手势决定表达**：同一图形快画慢画 → 相同的音高与节奏骨架、相同的
  确定性 seed（由归一化轮廓哈希得出）；力度与休止来自真实手势速度与停顿
- **六种变奏**：移调/节奏变奏/片段化模进/倒影/逆行/装饰音，全部在音级空间内变换，
  由 seed 驱动的确定性随机选择参数，内置辨识度守卫（轮廓/节奏/素材至少保留其一）
- **自动作曲**：主题捕获后自动生成七段式短作品（30–60 秒）：
  引子(主音持续音)→主题→变奏A(移调)→变奏B(片段化+音区)→发展(最密)→再现(主题回归)→
  尾声(主和弦解决渐弱)；Escape 随时打断
- **清空重画**：🧹 Clear & Start Over 按钮或 **N / Delete 键**随时清空已画图形、
  停止一切播放并回到空白画布（讲解/作曲进行中也可用）
- **音乐记忆**：最近 5 个几何主题本地保存，可随时重播
- **原理讲解**：🎓 按钮语音讲解动机提取原理和六种变奏——每讲一种就用当前主题
  （或内置示例）实际演奏一遍，语音与音乐交替进行；作品播放中可随时点
  重播主题/播放作品从头重新开始
- 合成器：sine+triangle 混合 + 低电平谐波层 + 低通滤波 + 小混响（合成脉冲响应），
  与学习模式共用 AudioContext，互不干扰

### 手势演奏（Hand Play）

按 <kbd>G</kbd> 或点击顶部 **🖐️ Hand Play** 标签，用摄像头把手的运动变成声音
（MediaPipe 手部追踪，模型与 WASM 全部本地打包，离线可用）：

- **自由演奏**：食指指尖位置直接驱动声音——左右是声像、上下是音高，
  与全软件一致的映射；量化音高模式下就是一件"空气乐器"
- **沿图形描摹**：手的位置驱动主动探索引擎——手在图形线条上有清晰主音、
  离线变轻噪声，经过顶点/交点触发提示音，线条吸附同样生效
- **捏合手势**：拇指与食指捏合（带迟滞防抖），朗读手当前的位置
- 手离开画面自动静音并播报；画面镜像显示（手向自己的右边动 = 声音向右）

摄像头权限：打包版会正常弹出授权；开发模式建议从自己的终端运行
`npm run dev`（权限归因到终端）。检测到的坐标经过指数平滑消除抖动。

### 语音教学导览（Voice Tour）

按 <kbd>T</kbd> 或点击顶部 **🎙️ Voice Tour** 按钮，启动内置的语音辅助教学系统。
它面向第一次使用的学生，用系统语音（离线）+ 真实声音演示 + 动手任务，
分 13 步讲解软件的使用方法和声音逻辑：

1. 声像（左/中/右三个演示音）与音高（低/中/高）如何对应位置
2. "移动的声音就是线条"：水平线与上升斜线的实听对比
3. 顶点点击音、闭合琶音（三角形演示）、交点脉冲（十字演示）
4. 三种模式的动手练习：按 Space 完整听一遍、按 → 逐边听、按 E 进入探索并移动指针

导览中只需四个键：<kbd>N</kbd> 下一步、<kbd>P</kbd> 上一步、<kbd>H</kbd> 重听本步、
<kbd>Escape</kbd> 退出（探索模式中会先退出探索）。动手任务的按键会真实生效，
完成后有答对音效和随机鼓励语；完成整个导览会记录在本地，不再强制提示。

### 三种播放模式

1. **连续轮廓播放**：声音点沿整个图形轮廓连续移动，感知整体形状与闭合性。
2. **分段学习**：每次只播放一条边，用 ←/→ 切换，状态栏读出边的序号、方向、斜率类型和长度。
   平滑曲线（圆、弧、正弦等）整段算作**一条曲线边**，不会被采样点切碎。
3. **主动探索**：方向键控制声音指针在坐标空间自由移动，指针每跨过一条网格线
   就语音播报当前坐标（中心原点、带正负，如"负 2，3"）；鼠标在主画布上移动同样按格实时播报。指针靠近线条时发声、
   离开时只有轻噪声；靠近顶点/交点触发提示音；S 开关吸附，F 自动沿线前进。

### 聆听要领

- **水平线**：声像从左移到右，音高不变
- **竖直线**：声像不动，音高持续升高
- **上升斜线**：声像右移同时音高升高；**下降斜线**：声像右移同时音高降低
- **陡与缓**：陡线音高变化快、声像移动少；缓线相反
- **多边形**：每个顶点一声"咔哒"并短暂停顿；回到起点时是三音上行的闭合音
- **圆形**：连续平滑、周期性的声像与音高变化，没有顶点声
- **十字/X 形**：两条线依次播放，穿过交点时有双脉冲提示音

### 教师编辑器

点击坐标区域添加顶点（自动连线）、拖动顶点修改、按坐标精确添加/编辑顶点（-5…+5 单位制）、
多条独立线路、闭合开关、指定起点、顺/逆时针、自动交点检测、保存到图形库、
导出/导入 JSON。

### 教学练习

四个阶段：声音坐标 → 基础线条 → 完整图形 → 几何关系。
题型包括位置判断、线型识别、比较陡缓、图形识别、数边数/顶点数、闭合判断、
斜率方向、平行/相交/垂直关系。每题可重播、慢速重播、分段播放、查看文字解释。
**全键盘语音流程**：出题即朗读题干与全部选项；空格=听声音、数字键 1-4=作答、
P=重听题目、H=听讲解、Enter=下一题——全程无需鼠标。
本地记录本次会话正确率、答题次数、重播次数、平均答题时间及各阶段累计成绩。

## 声音映射逻辑

程序内部使用标准化坐标 `x, y ∈ [0, 1]`（x=0 最左，y=0 最下）；
**界面显示与语音播报统一采用以中心为原点的坐标系**：-5 … +5 网格单位，
右正左负、上正下负，负数朗读为"负 / negative"。图形 JSON 与内部数据仍为 0..1。

```ts
pan  = x * 2 - 1                                   // 声像 -1（左）~ 1（右）
midi = minMidi + y * (maxMidi - minMidi)           // 默认 48（C3）~ 84（C6）
freq = 440 * 2 ** ((midi - 69) / 12)               // MIDI → 频率
```

- **两种音高模式**：**默认量化到音阶**（C 大调，可选半音阶 / 五声 / 全音）——听到的是音符的变化而非连续频率滑动；设置中可切回连续滑音。**平滑曲线（圆、弧）在整图播放时自动使用连续滑音**，保证曲线的流畅周期感不被量化切碎。
- **参数平滑**：频率与声像用 `setTargetAtTime` 平滑滑动，起止有淡入淡出，无爆音。
- **时长**：每条边 `时长 = 长度 × 3000ms ÷ 速度倍率`，限制在 300ms ~ 8000ms；
  平滑曲线按整条路径长度分配，保证圆形等曲线连续流畅。
- **播放起点**：开放线从最左端点（同 x 取较低者）；闭合图形从最左顶点
  （同 x 取较高者），默认顺时针，可切换逆时针；教师可指定起点。
- **顶点**：短促点击音 + 可调停顿（0~500ms，默认 150ms）；
  **交点**：双脉冲音；**闭合**：三音上行琶音；与开始/结束/对错提示音均明显不同。
- **多线路图形**（十字、平行线等）按线路依次播放，不会同时发声。

## 图形 JSON 格式

```jsonc
{
  "id": "custom-abc",             // 唯一 id
  "name": "我的图形",
  "type": "custom",
  "points": [                      // 顶点，坐标 0~1
    { "id": "p1", "x": 0.2, "y": 0.3 },
    { "id": "p2", "x": 0.8, "y": 0.7, "cue": false }  // cue:false = 曲线采样点，不触发顶点音
  ],
  "segments": [                    // 线段按 order 排序串成路径；不连续处自动分为独立线路
    { "id": "s1", "startPointId": "p1", "endPointId": "p2", "order": 0 }
  ],
  "closed": false,
  "startPointId": "p1",           // 可选：指定播放起点
  "playbackDirection": "forward"  // forward | clockwise | counterclockwise
}
```

导入时会做完整校验：id 唯一性、线段引用有效性、坐标自动限制到 0~1，
非法数据会给出中文错误说明且不会导致程序崩溃。

```
electron/main.ts          Electron 主进程
scripts/dev.mjs           开发启动脚本（Vite + Electron）
src/
  audio/                  声音引擎（独立模块，可单测）
    AudioEngine.ts          AudioContext、主声部、音量总线、淡入淡出、噪声提示

    ScaleQuantizer.ts       音阶量化
    PlaybackScheduler.ts    轮廓遍历调度、顶点停顿、交点脉冲、闭合、循环、暂停恢复
    CueSoundEngine.ts       8 种提示音合成
    ExplorationEngine.ts    主动探索指针、吸附、自动沿线
  geometry/               几何逻辑（纯函数，可单测）
    geometryTypes.ts / shapeLibrary.ts / traversal.ts /
    intersections.ts / slopeAnalysis.ts / nearestPoint.ts / shapeValidation.ts
  state/                  React Context + useReducer 状态、localStorage 持久化
  app/                    引擎单例、动作上下文、文字描述工具
  components/             界面组件（图形库、画布、设置、控制栏、编辑器、练习、斜率对比）
  i18n/                   英文源文案 + 中文词典的轻量国际化
  gesture/                MediaPipe 手部追踪（HandTracker + 纯数学 handTracking）
  instrument/             乐器创作模式（全部纯逻辑可单测，发声层除外）
    models.ts / scales.ts   数据模型；演奏音阶 + 迟滞防抖
    GestureAnalyzer.ts      实时特征（速度/曲率/转角/闭合）+ 离线轨迹处理
    MusicalMapper.ts        特征 → 合成参数（非线性动态、articulation）
    LiveInstrument.ts       演奏合成器（双振荡器+谐波层+包络+滤波+混响）
    ThemeExtractor.ts       轨迹 → 8–12 音符动机 + 确定性 seed
    VariationEngine.ts      六种变奏 + 辨识度守卫
    CompositionEngine.ts    七段式作品计划（纯函数）+ 演出调度器
    themeMemory.ts          音乐记忆持久化
```
